⚙️ Preprocessing Pipeline
1 Duplicate Removal

Drop exact duplicate rows to prevent data leakage and inflated metrics.

2 Invalid Value Clipping

Convert negative count/length values to NaN. Validate binary columns ∈ {0,1}. Bound ratio columns to [0,1].

3 Median Imputation

Fill remaining NaN values with training-set medians — robust to outliers. Fit only on training split.

4 Stratified Train/Test Split — 80/20

Stratified split preserves class proportions. Train: 80%, Test: 20% (held-out, never seen during training).

5 StandardScaler (scale-sensitive models only)

Applied to Logistic Regression and Naive Bayes. Tree models (Decision Tree, Random Forest) use raw features — scaling doesn't affect split decisions.
